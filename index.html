One-time setup — Apps Script Web App (deploy method)

This one script fetches both your sheets by their IDs (already filled in below) and hands the dashboard one JSON reply — no query params, no second link, no publish-to-web needed.

1. Open either spreadsheet → Extensions → Apps Script.
2. Delete the placeholder code and paste this in as-is — both sheet IDs and the tab's gid are already filled in: 

function doGet(e) {
  var SHEETS = {
    monopoly: { id: '1rkcPCeOuh9Ueuq87TGxxzgcwLpn2v3B2oMBO-H71P4g', gid: 663292535 },
    ready:    { id: '18LjLqXlklibHPu_QhcS4ZJPUaJaIKedqvYfR6Celetc', gid: 663292535 }
  };
  var result = {};
  Object.keys(SHEETS).forEach(function(key){
    var cfg = SHEETS[key];
    try {
      var ss = SpreadsheetApp.openById(cfg.id);
      var sheet = getSheetByGid(ss, cfg.gid);
      result[key] = sheet.getDataRange().getDisplayValues();
    } catch (err) {
      result[key] = { error: err.message };
    }
  });
  return ContentService.createTextOutput(JSON.stringify(result))
    .setMimeType(ContentService.MimeType.JSON);
}

function getSheetByGid(ss, gid) {
  var sheets = ss.getSheets();
  for (var i = 0; i < sheets.length; i++) {
    if (sheets[i].getSheetId() === gid) return sheets[i];
  }
  return ss.getSheets()[0];
}

function authorize() {
  var ss1 = SpreadsheetApp.openById('1rkcPCeOuh9Ueuq87TGxxzgcwLpn2v3B2oMBO-H71P4g');
  var ss2 = SpreadsheetApp.openById('18LjLqXlklibHPu_QhcS4ZJPUaJaIKedqvYfR6Celetc');
  Logger.log(ss1.getName() + ' | ' + ss2.getName());
}

3. Before deploying, run it once to grant access: pick authorize from the function dropdown at the top → click Run ▶ → approve the permissions popup (Advanced → Go to project → Allow).
4. Click Deploy → New deployment → gear icon → Web app.
5. Execute as: Me, Who has access: Anyone → Deploy.
6. Copy the Web app URL it gives you (looks like https://script.google.com/macros/s/AKfycb.../exec) and paste it, exactly as-is, into the single box above. Hit Connect — done.

If either sheet comes back with an error after this, double-check the id and gid values above against the sheet's URL. Sheets are matched by gid (the tab's internal ID, from the sheet's URL after #gid=) instead of tab name, so renaming a tab won't break this.

Load your sheets

In Google Sheets, select the full range of a tab (including the header row that starts with “Timestamp”) → Copy (Ctrl/Cmd+C) → paste it into the matching box below → click Parse & Load. This works with tab-separated data straight from Sheets/Excel. Nothing leaves your browser — parsing happens locally.

How this dashboard reads your columns

Monopoly expects: Timestamp, Unique ID, Order No., Customer Name, Delivery Date Promised, Link of PO, Material, Advance received, PDC Link, Ordered Quantity, Units, Sales executive, Dispatched, Pending, then four Planned/Actual/Time Delay stage triplets, then Order Status.

Ready expects: Timestamp, Unique ID, Order No., Customer Name, Delivery Date Promised, Material, Advance received, Quantity, Units, PDC Link, Sales Executive, Planned, Actual, Status, Time Delay, then Order Status.

Extra/blank columns are fine — the parser locates the header row automatically and matches by column name.
